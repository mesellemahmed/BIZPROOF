# BIZPROOF V0.14 — Design Freeze

V0.13 produced a frozen negative prospective result: no external
candidate reached a formal certification obligation.

V0.14 is therefore a new development phase.

The observed V0.13 120-case cohort may be used only for diagnosis and
generic capability development. It is no longer a prospective holdout.

Before any V0.14 engine modification, six untouched reserve projects
from the previously frozen 18-project universe are designated as the
confirmatory project-level holdout.

The existing frozen cohort-construction algorithm is reused without
semantic retuning to obtain 10 cases per reserve project, balanced as
2 cases in each of the five frozen semantic strata.

No reserve outcome may be observed before the V0.14 engine freeze.
