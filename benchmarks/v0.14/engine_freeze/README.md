This checkpoint freezes the V0.14 certification engine before any
confirmatory-reserve outcome is observed.

- development corpus: 120 previously observed V0.13 cases;
- Wave4 baseline: 1/120 certified;
- Wave5D: 3/120 certified;

Frozen V0.14 claim boundary:

- A1 parametric certification under explicit semantic boundaries;
- observation-scoped A1 certification where explicitly reported;
- no whole-program equivalence claim for OSSS;
- no general nullable/None semantics;
- no opaque ordering semantics;
- no certification of pure boundary passthrough;
- no candidate-specific adapters.

After this checkpoint, source or test changes to the V0.14 engine are
forbidden for the confirmatory-60 campaign.

Any future capability change belongs to a new version and a fresh
prospective cohort.
