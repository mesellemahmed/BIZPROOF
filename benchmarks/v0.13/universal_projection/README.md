# BIZPROOF V0.13 — Universal Semantic Projection Layer

This development corpus validates generic structural semantic extraction.

The layer does not certify business meaning.

It identifies evidence-bearing observations without candidate IDs,
project IDs, historical target tables, or handwritten semantic adapters.

Capabilities:

- SCALAR_VALUE
- STRUCTURED_VALUE
- OPAQUE_BINDING
- NESTED_LOGIC
- STATE_EFFECT

Opaque external observations remain semantically uninterpreted until
a validated contract is available.

State/effect observations describe externally visible writes or effect
calls; they do not claim equivalence yet.

This layer is the generic intermediate representation used by the
subsequent universal certification closure.

The frozen external V0.12 cohort is forbidden during development.
