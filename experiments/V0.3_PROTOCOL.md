# V0.3 Experimental Protocol

## Objective

Evaluate BIZPROOF on a fixed business-oriented benchmark whose ground truth is computed independently from the symbolic verifier.

## Research question

Can BIZPROOF correctly classify correct implementations and semantic business-rule violations across multiple business domains while preserving valid replayable evidence?

## Dataset

The fixed catalog contains 60 rules:

- Banking: 20
- E-commerce: 20
- Insurance: 20

Each rule is instantiated as:

- one correct implementation;
- four intentionally non-equivalent semantic mutants.

Total full benchmark size: 300 cases.

## Required success conditions

- oracle-label mismatches = 0;
- enum/Z3 disagreements = 0;
- Z3 false PROVED = 0;
- Z3 false DISPROVED = 0;
- unexpected UNKNOWN = 0;
- invalid replayed counterexamples = 0;
- missing counterexamples for detected mutants = 0;
- unexpected crashes = 0;
- mutation kill rate = 1.0;
- proof coverage = 1.0 for this supported subset.

## Interpretation

Passing V0.3 validates the verifier on this curated bounded benchmark only. It does not demonstrate correctness for arbitrary Python, external industrial code, or human usability.
